What is this?

Real-time aggregated orderbook combining L2 order data from 4 crypto exchanges (Binance, Coinbase, Kraken, Bitstamp) into a single unified view. Each row shows total liquidity at a price level across all exchanges, with colored bars showing each exchange's contribution. Price levels are grouped into bins for readability.

Runs entirely in your browser — direct WebSocket connections to each exchange, no backend needed. Zero dependencies, 16KB bundle.

Also available as a CLI tool: bun run src/cli.ts BTC — run --exchange=binance for a single exchange or --depth=30 for more levels.
