What is this?

A real-time aggregated orderbook that combines L2 order data from 4 crypto exchanges (Binance, Coinbase, Kraken, Bitstamp) into a single unified view. Each row shows the total liquidity at a price level across all exchanges, with colored dots indicating which exchanges contribute. Price levels are grouped into bins for readability.

Everything runs in your browser — direct WebSocket connections to each exchange, no backend needed. Zero dependencies, 13KB bundle.

Also available as a CLI tool: bun run src/cli.ts BTC — run --exchange=binance for a single exchange or --depth=30 for more levels.
